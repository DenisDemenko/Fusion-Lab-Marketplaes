# Fusion Lab Marketplace — глосарій

Термінологія домену. Без деталей реалізації — див. `ROADMAP.md` для плану
та `docs/adr/` для обґрунтованих архітектурних рішень.

## Учасники

- **Покупець (Buyer)** — користувач, що купує курси, книги або товари.
- **Продавець (Seller)** — користувач із власним кабінетом, що виставляє
  лістинги (курси/товари/книги) на продаж і отримує виплати за вирахуванням
  комісії маркетплейсу.
- **Адмін (Admin)** — модерує каталог, користувачів, бачить усі замовлення
  й комісії; без ліміту квот.

## Каталог

- **Лістинг (Listing)** — одиниця каталогу: курс, фізичний товар або книга.
  Книги потрапляють у каталог через API-міст з Book_Creality (окрема
  система, що книгу створила) — Marketplace їх не редагує, лише показує
  й продає.
- **Категорія / Атрибут** — класифікація лістингу для пошуку й фільтрів.

## Замовлення

- **Кошик (Cart)** — тимчасовий набір лістингів перед оформленням.
- **Замовлення (Order)** — зафіксований намір купівлі; складається з
  Order Items (по одному на лістинг), має статус і повʼязаний платіж.
- **Платіж (Payment)** — транзакція через LiqPay, привʼязана до Order.

## Гроші продавця

- **Комісія (Commission)** — частка від суми замовлення, яку утримує
  маркетплейс; ставка може залежати від продавця/категорії.
- **Виплата (Payout)** — переказ продавцю накопиченої суми за вирахуванням
  комісії, за визначений період.

## Утримання покупців

- **Промокод (Promo Code)** — код, що дає знижку на замовлення.
- **Loyalty-бали (Loyalty Points)** — нараховуються за покупки, витрачаються
  як часткова оплата наступних замовлень.
- **Кешбек (Cashback)** — повернення частини суми покупки у формі
  loyalty-балів (не окрема сутність — механізм нарахування балів).
- **Реферальна програма (Referral)** — Покупець запрошує іншого користувача
  через реферальне посилання; за перше замовлення запрошеного
  запрошувач отримує бонус (у loyalty-балах). Флагманський кейс для
  повного доменного моделювання — див. `docs/adr/` коли дійде черга.

## Комунікація

- **Сповіщення (Notification)** — односторонній сигнал через WebSocket
  (нове замовлення → продавцю, зміна статусу → покупцю).
- **Чат (Chat)** — двосторонній діалог Покупець↔Продавець про конкретний
  лістинг, до або після покупки.
- **AI-асистент (AI Assistant)** — чат-бот для Покупця: відповідає на
  питання про курси/товари, допомагає з вибором. Відрізняється від Chat —
  співрозмовник не Продавець, а AI.
